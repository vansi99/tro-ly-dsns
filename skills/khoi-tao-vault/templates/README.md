# Vault của Trợ lý ĐSNS

- `Inbox/`: ghi nhanh chưa phân loại
- `Ghi-chu/`: ghi chú theo ngày (nhắn bot "ghi lại: ...")
- `Nguon/`: link đã lưu kèm tóm tắt
- `Voice/`: lời chép từ voice note
- `Nhan-Duyen-Qua/`: bài Nhân Duyên Quả đã nạp
- `Ban-tin/`: bản tin sáng mỗi ngày
- `Chi-muc-may/`: chỉ mục tài liệu trong máy (do `/nap-may` tạo)
- `tac-phong.md`: cách trợ lý xưng hô và viết
- `nap-may.yaml`: thư mục tài liệu được nạp

Mở thư mục này bằng Obsidian để đọc và sửa ghi chú như sổ tay.
